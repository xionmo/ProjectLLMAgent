## 更新阅读版

使用 Python 3 和 `markdown-it-py`。依赖记录在 `requirements-docs.txt`；在已有相应依赖的环境中运行：

```bash
python3 scripts/render_document.py
```

主要文档变更应记录版本、日期、被修改的目标或标准，以及修改依据。

也可以指定一个或多个源文档生成阅读版（相对路径按项目根目录解释）：

```bash
python3 scripts/render_document.py docs/课程实施方案-v0.1.md docs/第一单元-模型计算与实验基线-v0.1.md
```

交互课件位于 docs/lessons/，其 HTML 是直接维护的源文件，不用上述静态 Markdown 渲染器覆盖。静态教案与阶段回顾仍从 Markdown 生成阅读版。
