语言模型学习的是条件分布

预测 xₜ 时，条件是它之前的 token。对一个序列的概率，可以按这条链逐项相乘。

一次预测

给定前缀，输出下一位置对整个词表的分布。

一段生成

选出一个 token，加入前缀，再调用相同参数的模型继续。

“按 token 生成”描述输出顺序；每次前向中的矩阵计算仍可大量并行。

logits：给每个候选一个实数分数

对象每个分量对应什么
隐藏表示 hₜ模型内部的特征坐标
词表 logits zₜ一个候选 token

普通全词表输出头一次给所有候选打分；训练标签提供本次观测到的目标，并不逐个手工提供“错误候选”。

softmax 把一组分数变成相对概率

共同加一个常数会在分子、分母中约掉；实现时常减去最大分数，避免指数溢出。

影响概率的是分数之间的相对关系。共同平移不变，整体乘一个系数通常会改变概率的集中程度。

ReLU 本身不保证输出和为 1。内部激活、概率变换与损失函数需要按用途区分。

给真实目标更高概率，会降低这一个位置的负对数似然。

单个样本损失更低，不足以说明泛化更强。训练、验证、测试损失需要连同数据切分和信息可见性一起解释。

梯度：损失对各个变量的局部变化率

对 one-hot 目标的 softmax 交叉熵，正确类别的导数为 pᵧ − 1；其它类别为 pⱼ。

导数的符号

说明小幅改变该变量时，损失往哪个方向变化。

导数的大小

说明局部敏感程度；实际更新还由学习率与优化器决定。

只看 softmax 概率曲线是否变平，不能判断完整损失到参数的训练信号。

反向传播沿相反方向应用链式法则，汇总所有依赖该参数的路径。

同一个参数在多个位置使用时，各位置对它的梯度会累加。一次前向产生激活，反向计算梯度，优化器再更新参数。

梯度与参数更新量不是同一个量

最简单的梯度下降：若梯度 g = −0.6，学习率 η = 0.1，

参数增加约 0.06；这与“给用户消息加一句纠正”是不同操作。

为什么有 √dₖ？

在下述简化假设下，点积方差为 dₖ，标准差为 √dₖ；除以它后，方差回到 1。

softmax 沿哪里计算？

固定查询位置 i，在一整行来源位置之间分配非负、和为 1 的权重。

负分数仍可对应可见位置。分数是否负，与位置是否被 mask 禁止是两件事。

√dₖ 的推导，从假设和单个乘积项开始

为分析维数的影响，假设 qℓ、kℓ 零均值、单位方差；两者独立，各乘积项之间也独立。

令 Xℓ = qℓkℓ，可得 E[Xℓ] = 0、Var(Xℓ) = 1。ℓ 是特征分量编号。

真实训练后的 Q/K 不一定满足这些假设。这是解释缩放设计的简化统计模型。

点积方差是 dₖ，标准差才是 √dₖ

独立项的协方差为 0，所以方差可相加；除以常数时，方差除以该常数的平方。

除以 √dₖ 后方差为 1。若除以 dₖ，方差反而变成 1/dₖ，会随维数继续缩小。

dₖ = 64 时用 8 缩放。某次 r = −16 得 s = −2，不代表该来源被禁止。Var 是这段理论分析的统计量；实际前向这里只除以 √dₖ，不额外计算一行分数的方差。

与大 batch 对照时，使用相同样本并控制随机性。浮点加法顺序不同可能产生小误差，需事先确定核对口径。

为什么除以 √dₖ？

这是分析点积随维数变化的统计尺度，不是要求每次点积都等于 √dₖ。为简化记号，固定一个 query 和 key，省略位置及头编号。

1. 明确分析假设

E[qℓ]=E[kℓ]=0,Var(qℓ)=Var(kℓ)=1

假设 qℓ 与 kℓ 独立，并且各乘积项之间独立。ℓ 是向量的分量编号。真实训练后的 Q/K 不一定满足这些条件；它们是这段推导的简化假设。

2. 每个乘积项的方差为 1

记 Xℓ = qℓkℓ。独立性使期望可以分开：

E[Xℓ]=E[qℓ]E[kℓ]=0
E[Xℓ2]=E[qℓ2]E[kℓ2]=1

因为零均值、方差为 1，所以二阶矩 E[q²]、E[k²] 都为 1。于是 Var(Xℓ) = E[Xℓ²] − E[Xℓ]² = 1。

3. 点积是 dₖ 个乘积项的和

r=q·k=∑ℓ=1dkXℓ
Var(r)=∑ℓ=1dkVar(Xℓ)=dk

独立性使不同项的协方差为 0，所以方差可以相加。方差为 dₖ，标准差才是 √dₖ。

4. 缩放后让方差不再随维数增长

s=rdk
Var(s)=Var(r)(dk)2=dkdk=1
为什么不是除以 dₖ？那样方差会变成 dₖ / dₖ² = 1/dₖ，随着维数增加继续收缩。这里选择补偿的是点积的标准差尺度。

例如 dₖ = 64，推导中的原始标准差为 8，所以除以 8。某次分数 r = −16 时，s = −2；这并不表示该来源被禁止，也不要求所有 s 都落在 [−1, 1]。

Var 是这里用于推导的统计量；实际注意力前向只除以 √dₖ，不额外计算一行分数的方差。缩放帮助控制送进 softmax 的典型分数差距；不能仅凭概率曲线的尖平判断整个模型的训练信号强弱。依据：原论文 §3.2.1 与脚注 1。
