1. 先看清每个对象是什么

标量表示“一个数”，是对象类型；缩放表示乘或除某个系数，是一种操作。两者不是同一个词。

本课用 r 区分未缩放的点积分数，用 s 表示缩放后分数。不同资料可能采用不同记号，阅读时先核对定义。

符号类型定义 / 来源作用与边界
qidk 维向量位置 i 当前表示的查询投影参与决定怎样匹配来源位置。
kjdk 维向量来源位置 j 当前表示的键投影与 q 做点积，两者维数需要匹配。
rij标量qi·kj原始匹配分数，可以为负，不是归一化权重。
sij标量rijdk缩放后的匹配分数，仍不要求落在 0—1。
mij标量允许为 0，禁止为 −∞在本例中，禁止未来位置参加本次汇合。
aij标量对一整行 s + m 做 softmax 后的第 j 项来源 j 的混合系数；对允许来源求和为 1。
vjdv 维向量来源位置 j 的值投影参与汇合的内容表示。
aijvjdv 维向量一个标量乘整个向量单个来源 j 的贡献，还没有汇总其他来源。
oidv 维向量∑jaijvj汇总各来源后的读取结果，会继续进入后续网络。

因此，dk 与 dv 可以不同：点积先把 Q/K 的分量合成一个数，得到的标量权重可以乘另一种宽度的 V。各个待相加的 V 则要有相同宽度。

aij= exp(sij+mij) ∑ℓexp(siℓ+miℓ)

ℓ 是遍历所有来源位置的求和索引。a 由整行分数共同决定，不是把每一个分数分别乘某个固定系数。

3. 更新量：学习率乘梯度，再取负号

这里讨论一个参数的简单梯度下降。g 是该参数处的损失梯度，η 是学习率，Δw 是实际更新量。

Δw=−ηgw新=w旧+Δw

−0.1 × (−0.6)Δw = +0.06
−(0.6 − 0.1) 算得 −0.5，不是本题的更新规则。得到正确数字之后，还要核对它是否来自正确运算。

4. 用旧知识作三个检查

为什么 r、s 可以为负，而 a 不能为负？

r、s 是分数，没有概率范围约束；a 经过指数与归一化，在本例中是非负的混合权重。

如果只改未来位置的 v₃，遮罩有效时 o₂ 会变吗？

在这次受控运算里不会：a₂₃ 为 0。真实模型的依赖检查还需要控制前缀、参数、随机性、位置与缓存条件。

梯度为 +0.4，学习率为 0.05，更新量是多少？

Δw = −0.05 × 0.4 = −0.02。参数沿负方向更新。

冻结权重后，未来 token 的改变若影响了较早位置，应排查未来信息是否进入了计算路径；这里讨论的是信息泄漏，不是“参数泄露”或新发生的训练更新。
