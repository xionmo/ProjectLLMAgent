Encoder、Decoder 与 Encoder–Decoder

结构典型可见性常见任务方向
Encoder-only已知输入的有效位置可以双向交互表征、分类、检索
Decoder-only自回归时读取当前及过去位置下一 token 预测与生成
Encoder–Decoder源输入双向编码，目标侧因果读取，并交叉查询源侧翻译、摘要等条件生成
Transformer 的定义不等于“所有 token 都无条件看全文”。原论文已经包含因果遮罩。

本书先读完整原论文结构，再明确课程实现保留或改变哪些模块。

Embedding：把离散 ID 查成可训练向量

输入

xᵢ 是词表中的一个整数 ID。

E 是“词表大小 × d”的可训练表。

输出

查出 E 的第 xᵢ 行，得到 d 维向量 eᵢ。

初始查表时，相同 ID 得到相同的 token 向量；位置与上下文随后进入。

ID 的大小本身没有连续语义距离。Embedding 的各维也不要求能逐一命名为人类概念。

位置表示：让模型能区分排列与位置

只有内容向量的 self-attention 对同时重排输入位置具有相应的等变性；模型还需要顺序信息。

原论文为不同特征维度选择不同频率的正弦和余弦，并与 token 向量逐分量相加。

pos 是位置，k 是一对特征维度的编号。课程初版用可学习的绝对位置表；RoPE 等机制作为后续明确替换的设计。

进入 Encoder 前：token 表示与位置表示相加

同一形状才能相加

每个 eᵢ 和 Pᵢ 都是 d 维。按位置排成 HE(0)，形状为 ns × d。

上标 (0) 的含义

这是第一层输入。后续 Encoder 层接收前一层输出，不重新做 token 查表。

√d 是原论文对词嵌入的缩放；注意力分数除以 √dₖ 是另一处操作。课程实现会在配置中记录自己的 embedding_scale。

Encoder self-attention：同一源序列提出查询并提供内容

HE 的每一行既产生自己的 query，也提供供其它位置读取的 key/value。

目标是为每个源位置形成包含上下文的新表示。输出仍按源位置排列，并没有直接生成目标句。

原论文的源输入已完整给出，因此通常允许读取全部有效源位置；padding 等无效位置仍要处理。

√dₖ 的推导，从假设和单个乘积项开始

为分析维数的影响，假设 qℓ、kℓ 零均值、单位方差；两者独立，各乘积项之间也独立。

令 Xℓ = qℓkℓ，可得 E[Xℓ] = 0、Var(Xℓ) = 1。ℓ 是特征分量编号。

真实训练后的 Q/K 不一定满足这些假设。这是解释缩放设计的简化统计模型。

点积方差是 dₖ，标准差才是 √dₖ

独立项的协方差为 0，所以方差可相加；除以常数时，方差除以该常数的平方。

除以 √dₖ 后方差为 1。若除以 dₖ，方差反而变成 1/dₖ，会随维数继续缩小。

dₖ = 64 时用 8 缩放。某次 r = −16 得 s = −2，不代表该来源被禁止。Var 是这段理论分析的统计量；实际前向这里只除以 √dₖ，不额外计算一行分数的方差。

Encoder 第一次 Add & Norm 产出 YE

主路

HE 经多头注意力和 WO 得到 UE。

旁路

直接把 HE 送到加法处；它是这一注意力子层的输入。

相加后按每个位置的特征做 LayerNorm，得到 YE，形状仍为 ns × d。

接下来 FFN 接收的是 YE，不是原始 token ID，也不是未加旁路的 UE。

延续同一组数值：相加，再逐行归一化

本例 WO 是单位矩阵，所以 UE = O。对上方矩阵的两行分别计算均值和方差。

这里每一行有 3 个分量，归一化结果并不只有 ±1。后续 FFN 将使用这个 YE。

Decoder 输入的是已知目标前缀的表示

训练

目标序列右移，BOS 放在起点；每个输入位置预测下一个目标 token。

生成

从 BOS 或给定前缀开始，把实际生成的 token 逐步加入输入。

HD(0) 由目标 token 的词嵌入和位置表示组成。后续解码层读取前一层输出。

较深层的目标表示还可以包含前面交叉注意力读入的源信息；“目标侧表示”不等于“只有目标文本的信息”。

Decoder self-attention：三路都来自目标侧，读取受因果约束

当前目标侧 H 同时产生 Q、K、V。对位置 i，允许读取已经可用的目标位置 j ≤ i。

机制与 Encoder self-attention 相同；区别在任务规定的可见性和输入序列来源。

注意力权重矩阵仍按 query 行、key 列排列。实现训练并行时，mask 必须覆盖每一层的信息通路。

Decoder 第一个 Add & Norm：先形成 Y₁

因果自注意力输出 Us 加回本层目标输入 H，再通过这一处 LayerNorm。

Y₁ 是接下来交叉注意力的查询侧输入；它还没有经过本层的交叉读取。

旁路输入、子层输出和归一化结果具有相同的位置数与主干宽度。

第二个 Add & Norm：把跨序列读取结果加回 Y₁

Uc 是交叉注意力经过多头组合后的输出，行数与目标 query 相同。

残差相加的两路是 Y₁ 与 Uc。不是把源矩阵 C 直接与目标矩阵相加。

这一步得到 Y₂，供当前 Decoder 层的 FFN 处理。

Decoder 的 FFN：对融合后的目标表示逐位置计算

结构仍是线性变换 → ReLU → 线性变换。输入 Y₂ 已包含本层的目标读取与源侧读取结果。

沿用同一职责解释：W₁ 构造候选特征，ReLU 按输入开关，W₂ 重组各通道的输出贡献。

同一 Decoder 层各位置共享这一组 FFN 参数；它不与 Encoder 的 FFN 自动共享参数。

目标有 nt 个位置，FFN 输出仍为 nt × d。

第三个 Add & Norm：完成这一 Decoder 层

FFN 输出加回它自己的输入 Y₂，经过第三处 LayerNorm，得到 Dnext。

若还有下一层，Dnext 继续作为输入；只有最终层的表示才送到顶端词表投影。

这一层的三处 LayerNorm 具有各自的可训练参数，不是一组 γ/β 在三个框中重复使用。

完整 Decoder 层：三条子层与三条残差路径

1
H → 因果自注意力 Us → LN₁(H + Us) = Y₁
2
Y₁ 查询 C → Uc → LN₂(Y₁ + Uc) = Y₂
3
Y₂ → FFN 输出 F → LN₃(Y₂ + F) = Dnext
每条旁路都连接当前子层自己的输入。源 C 是交叉注意力读取的内容，不是三条残差的公共输入。

这是原论文 post-LN 结构；课程序列模型的 pre-LN decoder-only 在后面的实现页单独标明。
