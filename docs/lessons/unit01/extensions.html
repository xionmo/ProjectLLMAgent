FlashAttention · 2022

涉及参数组织与训练/转换方案，不是无条件给任意权重打开一个开关。

U00–U01：先解释证据和目标

给模型纠正数字后答对，能证明参数更新了吗？

不能。先确认是否仅改变了上下文。训练需要损失、反向和更新证据；本题检查状态边界。

训练与验证 loss 都很低，为什么仍要检查因果性？

验证输入也可能把未来目标暴露给预测位置。数据集合独立不代表信息依赖合法；本题检查泄漏通路。

把所有词表 logits 加 100，概率和单标签交叉熵会变吗？

理想计算中不变，公共指数因子会约掉。数值实现应使用稳定的 log-softmax；本题检查相对分数与数值实现。

先自己解释，再展开对照。看过答案不等于已经通过独立检查。

U03：用失败对照证明检查有用

microbatch 长度不同，平均各自的 mean loss 就等价于大 batch 吗？

一般不等价。应按有效目标数量加权；且要控制随机性，并保持同样的更新次数和目标。

KV 版与完整前缀版生成的第一个 token 已不同，还能逐 token 比较后续 logits 吗？

不能把不同前缀下的差异全归为缓存错误。先用完全相同的给定前缀核对下一位置 logits。

少了一半乘加，为什么实测可能没有更快？

可能受访存、调度、数据布局或并行规模限制。需要固定测量口径，并分别看计算、搬运与启动开销。

第一单元的验收，需要哪些独立证据？

  • 能从 token、标签、mask 推导真实参与学习的目标。
  • 手写模型的形状、注意力数值和因果性检查通过，负例能被检出。
  • 小批次学习、恢复与梯度累积按约定核对。
  • KV 与全前缀结果等价，再报告分阶段计时和内存账。
