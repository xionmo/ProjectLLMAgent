W₁：从当前表示中构造候选特征

W₁ 的第 j 列决定怎样组合输入分量；b₁ⱼ 平移这个响应，也改变后面跨过零门槛的位置。

可以把 tᵢⱼ 暂时理解成“第 j 个特征检测器的响应”：它在当前表示中检测一个学到的方向。

原论文 base 配置为 512 → 2048：更宽的中间层提供更多候选通道，再配合非线性表达不同模式。单独线性扩维不会凭空增加输入信息，也不保证质量更好。

本节用 tᵢ 表示激活前向量，对应笔记中的 hᵢ；避免与主干 hᵢ 混淆。i 是 token 位置，j 是 FFN 通道；一个通道不保证对应“名词”等单一语义。

返回 FFN 主线 · 原论文 §3.3；检测器是本课的计算角色解释。

ReLU：按当前输入开关通道，并保留强度

开关由谁决定？

同一组 W₁、b₁ 遇到不同 yᵢ，算出的 tᵢ 可以不同，于是通过的通道也可以不同。

开关不是输出 0/1

正值保留原来的大小。zᵢⱼ 同时携带“通过了”和“以多大强度参与”的信息。

ReLU 自身没有可训练参数。负值归零是一条计算规则，不是在判断信息好坏；本节 zᵢ 是内部激活，不是词表 logits，也不是概率。

W₂：每个通道对应一个输出贡献方向

行向量记法下，W₁ 的第 j 列参与检测通道 j；W₂ 的第 j 行规定这个通道向输出的各分量贡献什么。

检测方向与输出方向分别学习：W₁ 决定对什么响应，W₂ 决定响应后贡献什么；zᵢⱼ 控制本次贡献的大小。

方向用 wⱼᵒᵘᵗ 命名，对应笔记中的 vⱼ，避免与注意力 Value 混淆。W₂ 可有正负分量，fᵢ 也可为负；这些响应不需要和为 1。

“写回”发生在哪里？接回第二个 Add & Norm

W₂ 先产出 fᵢ，各位置排成 FE；残差加法 YE + FE 把贡献接入主干，再按原论文 post-LN 顺序归一化。

Attention当前位置应从哪些可见位置读取什么内容？可以包含自身。
