三个注意力框：Q/K/V 从哪里来？

Encoder 自注意力：三路都来自本层输入 HE。

Decoder 自注意力：三路都来自本层输入 H；当前位置只能读取因果范围内的位置。

交叉注意力：Q 由 Decoder 的 Y1 投影产生，K、V 由 Encoder 最终输出 C 投影产生。

Feed Forward：每个位置独立计算

先线性变换，经过 ReLU，再线性变换回主干宽度。它在每个位置变换特征；同一层的所有位置使用同一组参数。

ReLU 对每个分量取 max(0, t)，把负值变为 0；这里处理的是内部特征。

原论文主干宽度 d = 512，FFN 中间宽度为 2048。本页小例子另外使用 d = 2。

本轮：交叉注意力怎样连接两条序列？

原论文讨论机器翻译：源句是已经给出的输入，目标句是逐步生成的输出。Encoder 把源句编码成 C；Decoder 下方的因果自注意力与 Add & Norm 产生 Y1，包含目标侧已知前缀的信息。交叉注意力让 Decoder 带着自己的查询，读取 Encoder 的结果。

继续放大注意力框：公式、对象与作用一起读

下标约定：i 是当前读取位置，j 是来源位置，b 是注意力头编号，B 是总头数；dk 是 Q/K 的特征维度，dv 是 Value 的特征维度。
数值例子从给定的两个头输出开始（B = 2）。下面的 Q/K/V 与权重公式解释它们的来源；本例没有给出一套用于推出这两个输出的完整参数。
1

把当前表示投影成 Q、K、V

Query 表达这次读取所用的查询特征；Key 提供匹配特征；Value 提供可被汇总的内容。W 是可训练参数，q/k/v 是本次计算产生的向量。

同一个头在不同位置共享投影矩阵。Q 和 K 都有 dk 个分量，V 可以使用不同的 dv。

2

先得到分数，再分配读取权重

r 是点积得到的标量分数，s 是缩放后的分数。对固定 i，在所有来源位置之间归一化，才得到标量权重 a。加性 mask 的 0 表示允许，−∞ 表示禁止。

这次 softmax 在来源位置之间分配权重；图 1 顶端的 softmax 在词表候选之间分配概率。

3

每个头读回一个向量，再拼接

aijvj 是一个来源的贡献；对所有允许来源求和，才是 oi。拼接 ci 保留同一位置各个头的读取结果。

给定：两个头分别读回 (2, 0) 与 (0, 3)。
4

WO 把各头的特征组合成主干宽度

这里组合的是同一个位置上各头读回的特征。WO 的系数可以为负，不要求归一化。

本例拼接后是 4 维，主干是 2 维，所以 WO 的形状为 4 × 2。

5

Add：把原表示和这次子层输出逐分量相加

旁路提供原来的 hi；主路提供 ui。两者必须有相同的分量数。相加会改变数值，不表示原信息在后续计算中永远保持不变。

6

Norm：对同一位置的特征归一化，再缩放与平移

把由输入计算的统计量、减均值并缩放、可学习变换这三件事分开看。

μi 与 σi2 是由位置 i 的 d 个分量计算出的标量；k 是分量编号。每个分量都减去同一个 μi，再除以同一个标准差项。γ、β 是 d 维可训练向量，⊙ 表示逐分量乘法，ε 是防止分母为零的小正数。

本例：相加结果为 (6, 2)，均值 μ = 4，方差 σ² = 4。若选择 γ = (1, 1)、β = (0, 0)、ε = 10−5，则归一化后的输出约为 (1, −1)。这是指定参数下的示例，不代表所有 LayerNorm 都产生该结果。

若 ui 是零向量，Add 之后仍是 hi；Norm 之后通常仍会发生变化。

为什么有些地方做归一化，有些地方不做？

LayerNorm 的标准化部分包含减去均值和除以标准差项；求均值、方差是前面的准备计算。完整模块还包含 γ、β 的逐分量变换。给定标准化结果 (1, −1)，选择 γ = (2, 0.5)、β = (0, 1)，最终得到 (2, 0.5)，均值是 1.25。这道小题检查的是能否区分“标准化后的中间向量”和“完整模块的输出”。

操作作用对象与范围想解决的问题
注意力分数除以 √dk每个 Q/K 点积分数；使用与维度有关的固定系数。在常用统计假设下，抵消点积典型尺度随维度增长的影响。它不按本轮数据减均值，也不把一组数变为概率。
注意力 softmax同一个 query 对所有来源位置的分数。构造非负、和为 1 的相对读取权重。
词表 softmax同一预测位置对所有词表候选的 logits。构造可用于预测与损失计算的候选概率分布。
LayerNorm一个位置的特征分量；每个位置计算自己的统计量。减少该向量整体偏移与尺度波动对后续计算的影响，再用 γ、β 学习特征的尺度与偏移。

动机：前面一层的尺度变化，会改变后面一层的工作方式

用不含投影偏置的自注意力作局部分析：如果整段输入 H 都放大 10 倍，那么 Q、K 各放大 10 倍，QKᵀ 就放大 100 倍。即使 dk 没变，softmax 所见的分数差距也会放大。原本只是表示的整体尺度变了，后续读取方式却可能大变；梯度与参数更新的数值尺度也会受到影响。

LayerNorm 提供了一种控制这种敏感性的办法。它的去均值部分消除整体平移的影响；忽略 ε 时，对非零方差向量的整体正数缩放也保持不变。实际 ε 非零时，后一性质通常是近似的。训练收益还取决于放置位置、初始化和优化器，不能只看某个归一化后的向量就断言有效。

为什么标准化后还要 γ、β？

均值、方差随当前输入改变；γ、β 是同一模块对各位置共享的可训练参数。前者整理每次输入的中心与尺度，后者让模型学习一套特征变换。γ、β 不会自动恢复每个输入被去掉的均值或尺度。

代价：归一化会改变信息，不应随处添加

例如两个词表 logit 向量 (2, 1, 0) 和 (20, 10, 0)：直接 softmax 时，最高分候选的概率分别约为 66.5% 和 99.995%，表达了不同的概率集中程度。若先对两者做 LayerNorm，暂忽略 ε 且使用相同 γ、β，它们会变成相同的向量，这种差异就消失了。这个例子讨论的是在词表 logits 上另加 LayerNorm；模型已有的隐藏表示归一化是另一处操作。

工程上先明确要解决什么：数值中心、尺度、概率约束，还是其它问题；再检查统计范围和被去掉的信息。例如，自回归模型若跨未来位置统计，可能引入新的信息泄漏通路。最后用受控实验比较训练稳定性、验证效果、实测速度和显存，并给不同结构合理的调参机会。

后续案例：RMSNorm（2019）检验去掉“减均值”、仅使用均方根缩放的方案；Pre-LN / Post-LN 分析（2020）研究同一归一化操作放在不同位置时对梯度与训练的影响。它们用于讨论可检验的结构选择，不作为任一配置在所有任务上更好的保证。
