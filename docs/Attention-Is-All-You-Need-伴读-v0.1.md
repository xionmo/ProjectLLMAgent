## 2. 第一轮：把单行手算接到矩阵公式

原文公式 (1) 写作：

~~~text
Attention(Q, K, V) = softmax(Q K^T / sqrt(d_k)) V
~~~

原公式这一行没有显式写因果 mask。对需要可见性约束的使用方式，可在 softmax 前加入相应的遮罩；原文在 §3.2.3 讨论 decoder 的这一限制。

先用以下记号查维度：

| 对象 | 形状 | 行表示什么 |
| --- | --- | --- |
| Q | n_q × d_k | 每个读取位置的 query |
| K | n_k × d_k | 每个可供读取位置的 key |
| V | n_k × d_v | 同一批来源位置的 value |
| A：归一化权重 | n_q × n_k | 一个 query 对各来源位置的混合系数 |
| O：汇合结果 | n_q × d_v | 每个读取位置获得的向量 |

Q/K 的特征维度须能匹配；K/V 的来源位置须一一对应。d_v 决定这个注意力运算的输出特征宽度，不必等于 d_k。这里的 V 表示 Value 矩阵，不能与其它讲义中表示词表大小的符号混为一谈。

## 3. 自建练习：只改变 V 的含义

沿用课堂中的三个位置。只算位置 2：

~~~text
q2 = 1
keys = [0, 1, 2]
values = [(2, 0), (0, 4), (9, 9)]
位置 2 的因果范围：位置 1、2
~~~

得到 a21=1/(1+e)，a22=e/(1+e)，a23=0。把 v2 从 (0,4) 改为 (0,8)，保持 Q/K/mask 不变：

~~~text
原 o2 ≈ (0.537883, 2.924234)
新 o2 ≈ (0.537883, 5.848469)
差值 Δo2 = a22 × Δv2
~~~

这项练习同时检查计算和三条依赖关系：

1. 匹配系数与被汇合内容是不同对象；只改变本次运算的 V 不改变 A。
2. 固定 A 后，O=A V 对 V 是线性运算。若只改一个来源向量，输出改变量就是它的权重乘该向量改变量。
3. 相同注意力权重仍可能产生不同输出，读取权重图时还要考虑 V 与后续计算。

本例第二分量恰好翻倍，是因为另一个可见来源 v1 的第二分量为 0。一般情况下，改 v2 的第二分量只改变相应贡献，不保证总输出第二分量翻倍。

这是一项局部、受控的干预。若改变原始 token 或其输入表示，Q/K/V 可能一起改变；后续层的注意力也可能随之改变，不能把局部结论扩成整网结论。

## 4. 从公式回到实现之前的关卡

能完成以下解释后，再用几行张量运算复现：

- 区分向量、标量权重与矩阵；指出每次乘法的维度。
- 用一句话说明每个输出向量由哪些来源构成。
- 预测只改变 Q、只改变 K、只改变 V 或改变 mask，分别可能影响哪些中间量。
- 说明注意力位置权重与最终词表概率的区别。
- 比较“整批矩阵运算”和“逐个 query 手算”为什么代表同一计算。
