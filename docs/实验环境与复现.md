# 实验环境与复现

课程当前以单张 RTX 4090、约 24 GB 显存作为本地实验设计起点。硬件、驱动、Python 与实际软件版本须以各次运行记录为准；能查询到 GPU 不代表训练和服务环境已通过验证。

## 环境发现

在项目根目录运行以下命令，重复采集时使用新的运行目录：

```bash
python3 scripts/probe_environment.py --check-torch --output runs/local-discovery-01/environment.json
```

脚本只发现当前解释器、已安装包和 GPU 查询状态；不安装依赖、不下载模型、不运行训练。报告采用新建模式，避免覆盖已有证据。查询被沙箱限制时会在报告中说明。

## 课程运行环境

训练与服务分别使用独立 Python 环境；按选定模型和引擎的官方支持矩阵确定 Python、PyTorch、CUDA wheel 与库版本。先做小型 CUDA 前向/反向验证，再执行模型训练。代码、配置、模型/processor revision 和数据切分随实验冻结。

图片输入实验先验证正确图片、无图、反事实换图三条路径，再研究分辨率、图数、训练与服务优化。实验入口见 [E01](../labs/E01/README.md)与[E13](../labs/E13/README.md)。

## 版本化与本地记录

Git 记录课程文档、源码、配置模板和可复现方法。原始运行目录、机器证据、备份、模型权重、环境文件与保密参考资料保留在本地，默认由 .gitignore 排除。需要共享实验结果时，另外整理不含秘密信息的报告与必要复现资产，再明确纳入版本管理。

共享盘目录不必迁移才能更换计算主机。正式性能测量分别记录数据所在介质、模型加载、冷暖缓存和设备计算；不要把存储或网络等待误归因于 GPU。
