# E13 图片输入、图文对齐与服务

完整实验契约见 [多模态教学包](../../docs/多模态图片输入-课程与实验设计-v0.1.md)。

E13-A 先验证图片实际进入模型及视觉依赖；E13-B 研究连接器与多模态适配；E13-C 研究图片服务、精度与缓存。首个候选为 Qwen/Qwen3-VL-2B-Instruct，尚未下载或在本机运行。

实施顺序：

1. 完成 E01 环境与小型 CUDA 验证，锁定 VLM/processor/库的版本。
2. 按源场景生成图片对，保存输入清单与独立真值；不得通过文件名或元数据泄漏答案。
3. 同模型执行正确图片、无图和反事实图片；换图后按新图真值评分。
4. 保存处理尺寸、视觉 token、输出、时延和内存，再做分辨率或图数对照。
5. 正确性基线稳定后接真实推理服务，最后再做适配与量化。

本目录当前只有实验入口，数据生成器、模型推理脚本与实验结果仍待实施。不能把教学包中的建议规模当作已运行数据。
